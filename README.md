# Store look demo

A ready-made static shop website: home page, shop, product, about, branches, brands, service centre and contact pages.
The name, text, prices and pictures are placeholders. It has no build step, so any web server can serve this folder as it is.

## Use it

In App Stacks, create a **Static website** stack and paste this repository's link as the Git source.

## Make it yours

Replace `DemoStore`, the sample text and the pictures in `assets/img/` with your own. The colours are at the top of `assets/style.css`.

The search and category filter work in the browser. The forms are samples and send nothing.
